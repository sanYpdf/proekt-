# User Stories

1. Как лаборант, я хочу просматривать список оборудования, чтобы быстро видеть состав кабинета.
   - Приёмка: приложение выводит инвентарный номер, тип, название, кабинет и состояние каждой записи.
2. Как лаборант, я хочу добавлять оборудование, чтобы вести актуальный учёт поступлений.
   - Приёмка: обязательные поля проверяются, повторяющийся инвентарный номер не сохраняется.
3. Как лаборант, я хочу находить запись по инвентарному номеру или кабинету, чтобы быстро получать сведения об устройстве.
   - Приёмка: поиск по существующему номеру или кабинету показывает подходящие записи; при отсутствии совпадений приложение сообщает об этом.
4. Как ответственный за кабинет, я хочу изменять сведения об устройстве, чтобы поддерживать данные в актуальном состоянии.
   - Приёмка: можно изменить поля записи; после сохранения изменения остаются после перезапуска программы.
5. Как ответственный за оборудование, я хочу удалять списанное устройство с подтверждением, чтобы не удалить запись случайно.
   - Приёмка: приложение показывает удаляемую запись и запрашивает подтверждение.
6. Как преподаватель, я хочу видеть допустимые состояния оборудования, чтобы единообразно оценивать его готовность.
   - Приёмка: доступны состояния «исправно», «требует ремонта» и «списано».
