# Система учёта инвентаря компьютерных классов

Консольное приложение на Python для ведения списка оборудования в компьютерных кабинетах. Оно хранит данные в JSON и позволяет просматривать, добавлять, искать, изменять и удалять записи.

## Требования

- Python 3.11 или новее
- Для запуска тестов: pytest

Приложение не требует сторонних библиотек для обычной работы.

## Запуск

Из корневой папки проекта выполните:

```bash
python main.py
```

На Windows при необходимости используйте `py main.py`. При первом запуске приложение читает демонстрационные данные из `data/inventory.json`.

## Возможности

1. Показать всё оборудование.
2. Добавить запись с проверкой обязательных полей и уникальности номера.
3. Найти записи по инвентарному номеру или кабинету.
4. Изменить сведения о записи.
5. Удалить запись после подтверждения.
0. Завершить работу.

Состояние выбирается из значений `исправно`, `требует ремонта`, `списано`. Дата поступления указывается в формате `ГГГГ-ММ-ДД`; дату и ответственного можно оставить пустыми. Изменения сохраняются сразу в JSON.

## Структура проекта

```text
main.py                 меню и взаимодействие с пользователем
inventory.py            операции и проверка данных
storage.py              безопасное чтение и запись JSON
data/inventory.json     демонстрационные данные (10 записей)
tests/                  автоматические тесты
USER_STORIES.md         пользовательские истории и критерии приёмки
```

## Запуск тестов

```bash
python -m pip install -r requirements.txt
python -m pytest
```

## Запуск в Docker (необязательно)

```bash
docker build -t inventory-app .
docker run -it --rm -v "${PWD}/data:/app/data" inventory-app
```

Папка `data` подключается с компьютера, поэтому изменения сохраняются после завершения контейнера.

## Формат записи

Каждая запись содержит инвентарный номер, тип, наименование, кабинет, состояние, дату поступления и ответственное лицо. Номер должен быть уникальным. Файл данных хранится в `data/inventory.json` в UTF-8.

## Ограничения

- Интерфейс работает в терминале.
- Одновременно предполагается работа одного экземпляра приложения.
- Данные хранятся в одном JSON-файле без разграничения прав доступа.
